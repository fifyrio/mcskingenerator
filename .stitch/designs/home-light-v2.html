The classic Steve model features 4-pixel wide arms, which feels bulkier and matches the original Minecraft character design. The Alex model features 3-pixel wide arms (Slim) for a narrower silhouette. Both use the standard 64×64 UV texture canvas.
Every modern Minecraft skin has two layers: the Base Layer (opaque body mesh) and the Outer Layer (which floats slightly above the body). The outer layer supports transparent alpha pixels, allowing you to design 3D hair strands, 3D armor plates, headphone earcups, and flowing coat skirts.
